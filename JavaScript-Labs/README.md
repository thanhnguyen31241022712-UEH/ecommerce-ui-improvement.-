## Mục tiêu

Hoàn thành ba bài thực hành JavaScript, từ nền tảng ngôn ngữ đến thao tác DOM, xử lý sự kiện và sử dụng jQuery cho hiệu ứng cũng như yêu cầu dữ liệu bất đồng bộ.

## Cấu trúc thư mục

```text
JavaScript-Labs/
├── index.html             # Trang portfolio và điều hướng chính
├── css/style.css          # Giao diện dùng chung
├── js/main.js             # Tương tác của trang chủ
├── assets/                # Ảnh đại diện cá nhân
├── Lab08/                 # JavaScript 1: Language Foundations
├── Lab09/                 # JavaScript 2: DOM and Events
├── Lab10/                 # JavaScript 3: jQuery
├── report/                # Báo cáo Word tổng hợp kết quả thực hiện
└── README.md
```

## Nội dung

- **Lab 08:** cú pháp JavaScript, Console, String, Date, Math, Array, Function và Object.
- **Lab 09:** lựa chọn và thay đổi DOM, sự kiện, biểu mẫu và validation.
- **Lab 10:** jQuery selectors, listeners, DOM, animation, GET request và jqXHR.
